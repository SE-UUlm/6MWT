# 6MWT

The six-minute walk test (6MWT) measures how far a person can walk in six minutes and is commonly used to assess functional exercise capacity. This project was developed as part of a Software Engineering project at Ulm University during the 2026 summer semester. Its mobile app records six-minute walk tests, estimates the distance covered and presents the result directly on the device.

The desktop Visualizer is a development tool for inspecting exported sensor data on maps and charts. It can also draw reference paths and replay different distance estimators to compare their behavior.

To use the app, install a release and record a walk. Developers can explore the repository's example recordings in the Visualizer and should start with Development for setup and Architecture for the data flow between sensors, storage and estimator replay.
