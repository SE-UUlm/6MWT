# Project Roadmap

This roadmap provides a high-level overview of the project's development from the initial concept to the final submission.

---

## Phase 1 — Project Setup & Planning *(May)*

**Milestone:** Development Environment Ready 

### Main Activities

- Brainstorming and project planning
- Flutter familiarization
- Analysis of the previous team's implementation
- Repository setup (GitHub, Wiki, Pull Request template, CI)
- Research on GPS integration in Flutter

---

## Phase 2 — Initial Development *(June)*

**Milestone:** First Functional Prototype 

### Main Activities

- GUI mockups and click dummy
- Initial GPS implementation in Flutter
- Research on Health Connect and Apple Health APIs

---

## Phase 3 — Core Application Development *(July – Early August)*

**Milestone:** End-to-End Walk Test Execution

### Main Activities

- Knowledge transfer with the previous development team
- GPS-based distance estimation
- Software architecture (feature-first structure, layered architecture, sensor abstraction)
- Sensor sample persistence
- Fitness assessment implementation
- Pedometer integration
- Patient profile persistence
- Logging infrastructure
- Walk session persistence

---

## Phase 4 — Core Feature Completion *(August)*

**Milestone:** GUI Development

### Main Activities

- Test instructions screen
- Home Screen
- Walk Test Screen
- Background execution and locked-screen support
- CI/CD setup

---

## Phase 5 — Feature Completion *(September)*

**Milestone:** Feature Complete

### Main Activities

- Completion of remaining application screens
- Session management
- Test abort handling
- Data export (CSV / JSON)
- GPS outlier detection
- Robust distance estimation

---

## Phase 6 — Finalization *(October)*

**Milestone:** Finalization

### Main Activities

- Continuous testing
- Outlier detection tuning
- Performance optimization
- Bug fixing and application stabilization
- Documentation and Wiki completion
- Final project review

---

> [!NOTE]
> This roadmap provides a high-level overview of the project's evolution. Detailed implementation tasks and day-to-day progress are managed separately using GitHub Issues.
